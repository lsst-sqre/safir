### New features

- Add new `safir.pydantic.YamlBaseSettings` class that can be used as a base class for application settings. It provides a method to read the class from a YAML file, handles the camel-case validation aliases needed to follow Helm conventions, and disables setting sources other than the YAML file and environment variables.
- Add new `safir.dependencies.config.ConfigDependency` class that can be used to create a FastAPI dependency that loads and parses a YAML configuration file lazily and returns the corresponding model.
