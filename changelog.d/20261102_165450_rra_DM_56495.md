### New features

- Add new configuration models `CloudSqlConfig` and `DatabaseConfig` and a new way of creating database engines, `engine_manager`, that transparently supports either databases with password authentication or Cloud SQL databases with IAM authentication. The latter avoids the need for either passwords or the Cloud SQL Auth Proxy and is transparently selected when a Cloud SQL configuration is provided. Using this new database engine management approach is recommended for all users of Safir's database support code.
- Add a new `initialize_with_engine` method to `DbSessionDependency`, allowing the dependency to be initialized with an engine created via `engine_manager` instead of wrapping engine creation in its `initialize` method.
- Allow the arguments to `safir.database.run_migrations_online` to be a configuration model instead of a URL and a password.
- Allow `safir.database.initialize_database` to take a configuration model instead of an already-created engine, in which case it will create the engine internally.
