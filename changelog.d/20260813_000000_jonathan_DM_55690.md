### New features

- The `safir.pydantic` type aliases (`EnvAsyncPostgresDsn`, `EnvRedisDsn`, `HumanTimedelta`, `IvoaIsoDatetime`, `SecondsTimedelta`, `UtcDatetime`) now have their own pages in the API reference. Documenteer 2.5's `documenteer.ext.autotypes` extension documents PEP 695 `type` aliases as first-class objects, so references to these aliases elsewhere in the documentation now link to their documentation instead of being suppressed.

### Other changes

- Update to Documenteer 2.5, which brings the documentation build to Sphinx 9 and drops nearly all of the manual nitpick-ignore configuration: the new `documenteer.ext.autotypes` extension resolves or gracefully degrades the cross-references that autodoc, automodapi, and autodoc-pydantic emit for modern typing constructs, so a strict nitpicky build passes without blanket ignores for external packages.
- Documentation builds in CI now prefetch intersphinx inventories from and submit link checks to Ook's caching services, authenticated with the `OOK_TOKEN` repository secret. Local builds and fork pull requests without the token transparently fall back to stock intersphinx and Sphinx's built-in linkcheck.
